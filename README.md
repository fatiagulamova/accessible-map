## Teknoloji Yığını
- **Mobil:** Flutter (Dart)
- **Backend:** Supabase (PostgreSQL + PostGIS)
- **Auth:** Supabase Auth (JWT)
- **Serverless:** Supabase Edge Functions (TypeScript)
- **Harita:** OpenStreetMap + flutter_map
- **Algoritma:** Dijkstra / A*

## Klasör Yapısı
- `mobile/` → Flutter uygulaması
- `supabase/` → Veritabanı migration'ları ve Edge Functions
- `docs/` → Mimari dokümantasyon
